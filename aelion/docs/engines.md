# AELION Engines Overview

AELION includes multiple specialized engines:

## Justice Engine
Handles case lookup, bias detection, and evidence mapping.

## Recall Engine
Stores events and reconstructs timelines.

## Emotional Engine
Analyzes tone, intent, and emotional projection.

## Home Engine
Provides diagnostics and hazard detection for home environments.

## Community Engine
Coordinates tasks, resources, and neighborhood safety.

## Governance Engine
Applies policies, reviews outputs, and logs decisions.

## Mining Engine (Optional)
Provides lightweight node participation for distributed networks.
